# 词隙使用说明

## 日常学习

启动后点击菜单栏当前单词，或按全局 `⌘K`。默认迷你卡片为 244 × 190 点；`⌘M` 可展开。空格揭晓词义，随后按 `1 / 2 / 3` 标记不认识 / 模糊 / 认识；按 `⌘Z` 可撤回。跳过和菜单栏轮换不会记录为已学。

“新学”只安排未学词及主动加词任务。“复习”只展示已到时间的词。今日待复习包含今天稍后到期的词，因此可能有待复习数量，但暂时没有可复习的词。选择不认识或模糊后，词可能仍会在今天到期，剩余数量也可能不减少。

偏好设置可调整每日目标、随机 / 字母顺序、发音、提示音、玻璃和深浅色。学习统计区分不同词数与评分次数；同词反复复习不重复计词，但每次评分会累计。

## 加词和易混词

`⌘⇧K` 打开快捷加词，带入剪贴板的短词或短语；已获辅助功能权限时也会优先读取选中文字。可以手动更改词与释义。已有词直接使用本地条目，未收录的英文词在已配置 API 时可自动补全；中文意思需按回车请求英文。确认加入后回到隐藏释义的卡片，完成主动回忆和评分才计为学习。

揭晓词义后按 `⌘B` 按需生成易混词。已有缓存时直接显示；Tab / 左右键切候选，回车保留，删除键排除，Esc 返回。辨析不自动加词，也不改动学习间隔。

## 导入词库

在偏好设置的“数据与词库”中导入 UTF-8 CSV / TSV。重复词按大小写不敏感合并，每次导入创建新词库，不替换已有词库。最少提供单词与释义；可使用以下表头：

```text
word,meaning,phonetic,example,example_translation
resilient,有韧性的; 能恢复的,,She is resilient.,她很有韧性。
```

字段内含逗号或换行时，按标准 CSV 规则用双引号包围，内部双引号写成两个双引号。中文表头“单词、释义、音标、例句、例句翻译”也支持。

## 备份与恢复

在设置中导出学习进度 JSON。此导出含学习状态与自建词库，不含独立的易混词缓存。完整备份建议：

1. 退出词隙。
2. 将 `~/Library/Application Support/WordGap/` 整个文件夹复制到另外的位置。
3. 恢复前先把目标电脑上现有 WordGap 文件夹另存一份。
4. 应用保持退出，用备份的完整文件夹替换该目录，再启动词隙。

没有图形化的备份导入按钮。只有单独 JSON 导出时，应先确认文件是学习进度格式，再在应用退出并备份当前目录后，将副本放到 `progress.json`；不要将统计 CSV 当成可恢复的备份。Key 不在这些文件内，迁移或重新编译后可能需要重新保存自己的 Key。

上一份 `progress.backup.json` 会随着后续保存更新，因此不能代替放在其他位置的独立备份。不要在应用运行时覆盖状态文件。

## 统计含义

新学 / 复习词数按当天不同单词去重；同一个词当天先新学再复习，可分别计入两项。“评分次数”记录每次操作。“认识”等自评不等于客观正确率。专注时长是前台卡片学习活动的估算，不代表精确学习时长。
